# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-11-26

### Added

- First version of `<gc-segmented-control>` and `<gc-segment>`: form-associated radio group (`name`, `value`, `required`, `disabled`, reset and history restore), sliding selection indicator, horizontal and vertical orientations, roving tabindex and arrow-key navigation (RTL-aware), `--segmented-*` CSS custom properties, `track` and `indicator` parts, light/dark defaults, forced-colors support, French and English validation message, TypeScript definitions, bilingual README and demo, Playwright tests, Custom Elements Manifest and VS Code data.
